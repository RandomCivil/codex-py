# Execution-mode abstraction above the Plan-step Executor

**ReAct amendment:** ADR-0021 supersedes this ADR's ReAct criterion-context, per-Tool-batch judgment, and judge-authored answer statements.

**Status: accepted and amended by ADR-0017.** Whole-task execution is modeled as an Execution mode: `direct`, `tool_agent`, `react`, or `plan_execute`. An explicit mode factory selects a mode and each returns one Execution answer; a future deterministic router may compose the factory after task analysis. The existing `Executor` remains exclusively the Plan-step Executor inside `plan_execute`. Only `plan_execute` participates in the existing durable run/recovery model; the other modes are ephemeral. A failed mode never escalates automatically. Criterion-enabled ReAct appends host-owned criterion status to each tool-round context and records progress only from a separate, locally validated `COMPLETION_PROGRESS` judgment over settled successful tool results. When the judge reports `ALL_COMPLETED=true`, it supplies the final `ANSWER` and ends ReAct immediately; ReAct without supplied criteria retains its existing terminal-response contract. `plan_execute` exposes its last successful Plan-step handoff without an additional model request. Tool-enabled ephemeral modes share one constrained Tool runtime per invocation. `tool_agent` executes only the first tool request from its sole model response and exposes that host-rendered result; later requests are ignored and traced; a tool or rendering failure is a failed answer. YAML gains `direct`, `tool_agent`, and `react` overrides alongside the existing components, each inheriting `model` defaults. All non-tool model responses use Line Protocol; native tool definitions remain provider-native.

## Considered Options

- Generalize the existing Executor to mean every execution path — rejected because it would silently invalidate its established one-Plan-step contract.
- Let task analysis choose a mode directly — deferred: task analysis is deliberately descriptive, and routing policy remains deterministic.
